INTERACTION GUIDE

Move the geometry.

Left drag / 左ドラッグ
3D: e₃ upright. 4D / CGA: free spatial orbit. / 3Dはe₃を上に保ち、4D / CGAは自由回転。
Right ↑↓ / 右ドラッグ上下
Change extra-axis latitude (0–90°), including over tips. / 点の上でも、現在の上方向と追加軸の緯度を変える。3Dでは動作なし。
Right ←→ / 右ドラッグ左右
CGA: exchange origin / infinity axes (0–90°). / CGAでは追加の二軸を切り替える。
Tip drag / 先端を左ドラッグ
Move in the view plane. Shift constrains to xy. / 視線に垂直な面で移動。Shiftでxy平面に制約。
Click / tap / クリック・タップ
Activate wheel / pinch. Escape or tap outside releases. / ズームを有効化。Escか図の外で解除。
Touch / タッチ
One finger: left drag. Two: right drag and pinch. / 一本指は左ドラッグ、二本指は右ドラッグとピンチ。
Coordinates / 座標
Edit hidden coordinates numerically. / 隠れた成分も数値で変更。
